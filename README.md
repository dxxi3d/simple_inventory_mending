# Simple Inventory Mending

![Minecraft](https://img.shields.io/badge/Minecraft-26.3-brightgreen)
![ModLoader](https://img.shields.io/badge/ModLoader-Universal-purple)
![Side](https://img.shields.io/badge/Side-SERVER-success)

Mending works anywhere in your inventory.

* Repairs equipped gear first, then items in the player inventory.
